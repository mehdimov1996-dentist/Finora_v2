# Finora — راهنمای ساخت APK

APK داخل محیط من ساخته نشد (Android SDK و اینترنت در دسترس نبود)، ولی پروژه کاملاً آماده‌ی ساخته شدن است. یکی از راه‌های زیر را انتخاب کنید.

## راه ۱: ساخت خودکار در GitHub (بدون نصب هیچ چیز)
1. یک مخزن (repository) جدید در GitHub بسازید و محتوای همین پوشه را در آن آپلود کنید.
2. به تب **Actions** بروید ← workflow به نام **Build Android APK** ← **Run workflow**.
3. بعد از ~۵ دقیقه، در پایین صفحه‌ی اجرا، فایل **finora-apk** را دانلود کنید. داخلش `app-debug.apk` است.
4. APK را روی گوشی نصب کنید (اجازه‌ی «نصب از منبع ناشناس» را بدهید).

## راه ۲: ساخت روی کامپیوتر خودتان
نیازمندی‌ها: Node.js 22+، JDK 21، Android Studio (برای Android SDK).

```bash
npm install
npx cap add android
npm run icons        # ساخت آیکن (اختیاری)
npx cap sync android
cd android && ./gradlew assembleDebug   # ویندوز: gradlew.bat assembleDebug
```
خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`
یا با `npx cap open android` پروژه را در Android Studio باز کنید.

## راه ۳: بدون APK (PWA)
پوشه‌ی `www` را روی یک هاستینگ HTTPS قرار دهید، در Chrome گوشی باز کنید و «Add to Home screen» را بزنید.

## نکته‌ها
- اطلاعات داخل حافظه‌ی همان برنامه ذخیره می‌شود. قبل از حذف برنامه، از **تنظیمات ← دانلود Backup** فایل پشتیبان بگیرید.
- APK بالا از نوع debug است و برای استفاده‌ی شخصی کافی است. برای انتشار در مارکت‌ها باید نسخه‌ی release با کلید امضای خودتان بسازید.

## اعلان قیمت و AI (نسخه‌ی جدید)
- **اعلان قیمت:** برنامه هر ۳۰ ثانیه (وقتی باز است) قیمت دسته‌های دارای نماد Binance را می‌گیرد و اگر وارد محدوده‌ی یک تحلیل شد، هشدار داخل برنامه + اعلان سیستم می‌دهد. اگر برنامه کاملاً بسته یا خواب باشد بررسی انجام نمی‌شود (برای آن سرور لازم است).
- برای اعلان روی اندروید، بعد از اولین اجرا دکمه‌ی «🔔 فعال‌سازی اعلان» را در بخش تحلیل بزنید (پلاگین `@capacitor/local-notifications` در package.json اضافه شده).
- **AI:** از «تنظیمات ← اتصال به AI» سرویس (Anthropic یا سازگار با OpenAI)، مدل و کلید API را وارد کنید. کلید فقط روی خود دستگاه می‌ماند و در Backup نیست.

## قیمت زنده‌ی معاملات باز، منابع قیمت، اعلان To-Do
- **معاملات باز:** هنگام ثبت معامله «منبع قیمت لایو» را انتخاب کنید (برای حساب کریپتو، حالت «خودکار» از Binance و روی نماد معامله مثل BTC/USDT کار می‌کند). قیمت هر ۳۰ ثانیه به‌روز می‌شود و سود/زیان شناور، درصد، «رشد با احتساب شناور» و خط‌چین نمودار را می‌سازد. رسیدن قیمت به حد ضرر/حد سود هم هشدار می‌دهد.
- **API قیمتی جدید:** تنظیمات ← «منابع قیمت (API)». آدرس https با `{symbol}`، مسیر عدد در JSON (مثل `data.price` یا `result[0].last`)، ضریب (مثلاً ۰٫۱ برای ریال ← تومان) و در صورت نیاز هدر/کلید. دکمه‌ی «تست» قبل از ذخیره قیمت را نشان می‌دهد. این منابع و کلیدها فقط روی همین دستگاه می‌مانند و در Backup نیستند.
- در نسخه‌ی اندروید (APK) درخواست API سفارشی مستقیم و بدون محدودیت CORS انجام می‌شود. در مرورگر/فایل HTML فقط APIهایی کار می‌کنند که CORS را مجاز کرده باشند.
- **اعلان To-Do:** مهلت (با ساعت اختیاری و یادآوری «به‌موقع / ۱۰ / ۳۰ دقیقه / ۱ ساعت / ۱ روز قبل») در اندروید به‌صورت اعلان زمان‌بندی‌شده‌ی سیستم ثبت می‌شود و حتی با برنامه‌ی بسته کار می‌کند. بدون ساعت، یادآوری ساعت ۹ صبح همان روز است. در مرورگر فقط وقتی صفحه باز است کار می‌کند.
- مجوزهای اعلان (POST_NOTIFICATIONS و SCHEDULE_EXACT_ALARM) را workflow خودکار به AndroidManifest اضافه می‌کند. اگر اعلان با تأخیر می‌آید: تنظیمات ← اعلان‌ها ← «دقت زمان‌بندی (اندروید)».
